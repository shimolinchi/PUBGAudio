## 2. 必须保持的规则

1. 使用本机客户端已溯源的声音，直接复制或提取；保留原始素材，不下载替代游戏音效。
2. 先确定轨迹、速度和动作时间，再沿轨迹渲染。脚步、车辆允许弯曲和停走，方向及距离连续变化。
3. 同一角色整条脚步轨迹固定同一地面；走、跑、冲刺及模拟左右脚都在同材质内部变化。禁止拿两种地面充当左右脚。
4. 远处声音占多数，同时保留近处外部反例、稀疏场景及少量纯背景场景。
5. 自身/外部身份由生成角色与素材来源确定。不能把所有近声标成自身；外部声音当前不进一步区分敌方与队友。
6. 物理发声、位置真值和混音中的可观测性分别保存。被掩盖的已保留声源仍有轨迹和活动真值，屏蔽相应正例监督。
7. 运输飞机独立于车辆；碰撞属于车辆事件；天气作为背景。未核验的素材不能凭听感猜测来源后混入训练。
8. 一个原声家族及其所有派生版本留在同一数据划分。每次改变生成行为使用新输出目录，保留旧数据、配方和试听反馈。

## 3. 类别、来源与素材

| 类索引 | 存档名称 / 模型名称 | 当前监督 |
|---|---|---|
| 0 | 脚步 / `footsteps` | 外部轨迹与自身活动分别监督 |
| 1 | 车船 / `vehicle` | 当前 v4 实际使用 8 个地面车辆家族；包括启动、发动机、制动、碰撞等事件 |
| 2 | 枪声 / `gunfire` | 外部轨迹与自身活动分别监督 |
| 3 | 运输飞机 | 独立类别，正例素材尚未补齐，监督 mask 为 0；当前三类模型不训练该类 |

类 1 的“车船”是现有存档名称，不表示当前 v4 已包含船或飞机。v4 场景实际使用 Buggy、CoupeRB、Dacia、Minibus、PickupTruck、Rony、Sedan、UAZ 家族。其他载具要先补齐并核验素材，再在新数据版本登记。

自身枪声使用客户端 `Local` 原声，自身车辆启停使用 `FPP`；对应外部版本与自身版本仍按同一原声家族隔离划分。自身脚步采用同地面素材的听者中心近似，持续发动机采用共享怠速素材的 RPM 近似，不能称为完整第一人称引擎还原。

素材清单共 691 条，包含新增 30 条碰撞、5 条天气录音。仅从动作齐全的家族选材：脚步需有 walk/run/sprint，车辆需有 idle/startup/shutdown，自身车辆另需 FPP 启停，枪声需有相应射击素材。

来源登记保留 bank/media ID、原始条目与 WEM/PCM/WAV 哈希。仅有流式前缀时，以完整 RIFF 长度及逐字节前缀定位唯一完整载荷后验哈希；不得补零伪造声音。正常再次混音依赖已准备的 WAV、`sources.json` 与 HRIR，不读取游戏进程。

## 4. 场景采样与密度

下列是规划阶段的比例。整轨筛选、自身策略和纯天气覆盖会改变最终声源数与实际可听密度，因此不能把计划比例当成成品统计。

| 项目 | 当前规则 |
|---|---|
| 长度与输出 | 每段 30 秒；44.1kHz 双声道 PCM16 WAV |
| 基础低 / 中 / 高密度 | 40% / 35% / 25% |
| 低密度布局 | 单类单声源 70%；两种类别 30% |
| 中密度布局 | 两种类别 55%；三种类别 35%；同类两个声源加另一类 10% |
| 高密度布局 | 三种类别 80%；同类两个声源加另一类 20% |
| 外部初始近 / 中 / 远 | 10% / 10% / 80%，按类别和密度分组安排 |
| 外部初始方位 | 0° 至 315°、间隔 45°，八个方向均衡安排；移动后的方位为连续值 |
| 自身策略 | 纯外部 25%；纯自身脚步/车/枪各 5%；外部混合自身脚步/车/枪各 20% |
| 天气 | 5% 场景覆盖为纯天气；其余场景以 20% 概率加入天气 |

近、中、远初始半径基值分别为 `9、32、168`（远档为 `105×1.6`），各乘随机系数 0.88–1.15。运动中按最终位置重新计算距离，不能沿用初始距离档。粗距离边界为 `sqrt(8×30)≈15.49` 和 `sqrt(30×90)≈51.96`：小于第一边界为近，达到第二边界为远。

成品 v4 的远处占比为 **84.688%**，分母是“外部声源的发声轨迹帧数”，包含按遮蔽规则不能监督的帧；不是远处文件占比，也不是远处可听正例占比。小集同口径为 88.206%。

低密度模拟前期较少声音，高密度模拟交战集中阶段；两者都可以出现远声和自身声音。当前没有复刻完整一局的阶段转移或安全区规则。

## 5. 轨迹、脚步与车辆动作

坐标以听者为原点：x 向右、y 向前，声源位于水平面。方位顺时针：0° 前、90° 右、180° 后、270° 左；距离为 `sqrt(x²+y²)`。

轨迹由速度节点和展开后的朝向节点定义，使用平滑插值，以 10ms 步长积分速度得到 XY。外部脚步和车辆再增加 50°–95° 的弯曲幅度；如果轨迹过于靠近听者，会调整朝向，必要时退回原轨迹。因此允许明显曲线，但不是强制每条轨迹都是同一条 S 曲线。

| 声源 | 当前动作规则 |
|---|---|
| 脚步 | 低密度一段短移动，中密度两段，高密度三段；段间停步。速度低于 0.15 不触发新落脚，低于 2.4 用 walk、低于 4.8 用 run，否则用 sprint |
| 落脚节奏 | 步频 `min(3.65, 1.55×速度^0.47)`，积分累计步相；停止时不重置步相或交替次序，已触发声音保留尾音 |
| 模拟左右脚 | 同一地面、同一步态的原声变体分成两个池交替取样；`simulated_foot` 仅表示合成节奏，原素材没有真实 L/R 标签 |
| 车辆 | 原生启动结束后移动；加速、短巡航、卸载减速、中途急刹停车、再次起步、最终停车后熄火 |
| 巡航平台 | 同速平台占移动区间约 2.5%，旧版为 18%；低加速度帧也会被归入巡航状态，不能用状态帧比例直接等同此参数 |
| 急刹 | 当前每条普通车辆轨迹都采用中途刹停模板，急刹区间最长 0.5 秒；此比例与碰撞概率不同 |
| 碰撞 | 有可用素材时，每条车轨迹以 40% 概率在中途停车点加入原生碰撞，事件增益 0.65–1.1，所属类别仍为车辆 |
| 枪声 | 当前枪手位置固定；按密度安排射击段和连发事件，没有实现同一角色边走边射击的身份关联 |

车辆启动、熄火、轮胎/制动/打滑和碰撞采用原声。持续发动机从怠速循环连续读取，按 RPM/负载调整播放速率与滤波，读取游标不断开。REV ADM3 `.model` 尚未解码，当前没有原引擎完整的档位、加速度声学或精确车体碰撞仿真。

自身脚步、枪声、车辆始终绑定听者相对原点 `(0,0)`。自身 `track_speed=0` 表示相对位置不动，`track_locomotion_speed` 表达驱动步态/RPM 的移动速度；不能因此把自身脚步当成完全没有动作。当前未用玩家世界位移联动全部外部相对轨迹。

## 6. 车内筛选与遮蔽

车内场景以存在 `source_role=self` 且类别为车辆的轨迹判定，使用两个阶段的规则：

| 阶段 | 条件与参数 | 结果 |
|---|---|---|
| 规划时整轨筛选 | 外部脚步候选保留概率 10% | 被丢弃候选不进入最终混音与轨迹标注 |
| 规划时整轨筛选 | 候选轨迹全段最小距离 ≥90 的外部车，保留概率 5% | 枪声不按此规则统一删除 |
| 保留声源的逐帧遮蔽 | 每声源相对其余声轨与背景的 SIR 门限 −30dB | 低于门限的发声帧关闭对应监督 |
| 外部脚步附加门限 | 相对自身车功率至少 −12dB | 与一般门限同时满足才可监督 |
| 远处外部车附加门限 | 当前帧距离 ≥90 时，相对自身车功率至少 −15dB | 距离按最终轨迹逐帧判断 |

规划阶段的“全段最小距离”来自 v4 动作/弯曲覆盖前的候选路径；逐帧遮蔽使用最终路径。固定试听场景跳过候选随机删轨，以便保留对照声源，但仍计算可观测性；不能用这 15 段试听反推训练集删轨比例。

SIR 根据分离声轨的窗口功率之和估算，分母为其余声轨/背景的功率和；不是直接测得的人耳可听阈值，也不是包含相位交叉项的混音实测功率。阈值是当前合成假设，应根据试听与实战反馈调整。自身活动同样有可观测性掩码。

## 7. 天气与易混淆原声

已核验沙尘暴 Inner、Outer、Center 三种循环；另有 PillarCompound 风声和 Mode_SLB Storm。后两者保留原始名称。暴风雪媒体 ID 269897396 仅查到命名，尚未唯一定位/解码，不作为已核验暴风雪加入。

天气保持原立体声关系；单声道素材复制到双耳，作为无单点方位的背景，不生成虚假的外部轨迹。天气源参考 RMS 为 0.045、峰值上限 0.35，场景增益随机 −8 至 +2dB，随机循环起点，循环过渡 250ms、片段边缘过渡 150ms。

完整 v4 有 867 次碰撞、707 段天气，其中 141 段纯天气。纯天气对脚步、车辆、枪声是负例，飞机仍不参与监督。轮胎/碰撞可与具体车体或地表不完全匹配，这属于当前素材近似，后续可按反馈补齐匹配素材。

## 8. 空间化、响度与音频连续性

外部声音使用 KEMAR diffuse 水平 HRIR，128 点，方位网格 5°，网格间插值。每 20ms 更新位置相关滤波并逐样本交叉过渡，保留滤波输入历史，避免每个轨迹节点重新起声。

距离增益和低通截止频率按下表在对数距离上连续插值，超出两端使用端点值：

| 距离（合成单位） | 增益 | 低通截止 Hz |
|---:|---:|---:|
| 1 | 1.15 | 16000 |
| 8 | 1.00 | 16000 |
| 30 | 0.50 | 7500 |
| 90 | 0.22 | 3500 |
| 400 | 0.045 | 1200 |

脚步/车/枪原声参考 RMS 分别为 0.065/0.085/0.09、峰值上限 0.4/0.42/0.55。外部声轨共同增益抖动 −1.5 至 +1.5dB，自身声轨 −6 至 +2dB；落脚事件另有 0.96–1.04 倍微扰。自身原立体声只用两耳共同系数，不分别归一化。

混音使用整批数据的共同主增益约束峰值 ≤0.7，不做逐片段或逐耳归一化。完整 v4 主增益约 0.310746，小集为 0.6；同一合成器生成不同批次时公共增益可以不同。试听不同批次时固定播放设备和音量，避免把播放音量差误认为距离规则变化。

当前没有完整房间混响、墙体遮挡、楼层高度、多普勒或传播时延仿真。共用低通延迟为 `64/44100` 秒；自身及天气也对齐这一延迟。

## 9. 每帧标注与训练转换

“每帧”指音频分析帧，不是 WAV 单个采样点。30 秒场景有 **2997 帧**，窗口 32ms、步长 10ms；标签时间为 `frame_right_edge_seconds − 0.016 − 64/44100`。有无声音都保存已保留角色的位置。

令 K 为声源数、T=2997：

| 字段 | 形状/含义 |
|---|---|
| `track_xy` | K×T×2；相对听者坐标 |
| `track_distance_units`, `track_azimuth_degrees` | K×T；连续距离、顺时针方位 |
| `track_class_index`, `track_source_role` | K；类索引，来源 0=external、1=self |
| `track_direction_valid` | K×T；自身恒为 0，自身 azimuth=0 只是占位，不表示前方 |
| `track_range_index`, `track_sector_index` | K×T；外部近/中/远 0/1/2、八方位 0–7；自身均为 −1 |
| `track_activity` | K×T；孤立声轨发声真值 |
| `track_observable` | K×T；发声且通过功率门限的估计状态 |
| `track_speed`, `track_locomotion_speed` | K×T；相对速度及驱动动作的速度，后者主要用于自身轨迹 |
| `track_motion_state`, `track_engine_state`, `track_gait_state` | K×T；运动、引擎、步态的诊断状态 |
| `track_collision_activity` | K×T；碰撞事件时间支持，与车辆类关联，不等同于可听性 |
| `activity`, `activity_loss_mask` | T×4×8；外部类/扇区活动及监督开关 |
| `range_index`, `range_loss_mask` | T×4×8；只有距离档唯一且可观测的活动单元有距离监督 |
| `self_activity`, `self_activity_loss_mask` | T×3；自身三类独立活动/监督 |
| `weather_present`, `background_power`, `self_vehicle_power` | T；背景存在及干扰功率 |

发声判定门限取该孤立声轨最大帧功率下方 35dB 与绝对 −90dBFS 功率底限的较大值。活动为 1 但被遮蔽时，保留活动/位置，将相关监督 mask 置 0，不能改成可训练的无声负例。聚合掩码还会因多个距离候选或保守遮蔽规则关闭，因此 `track_observable=1` 不保证所有训练头都使用该帧。

NPZ 是几何与声音真值。试听页面使用 50ms 轨迹点插值，逐帧 CSV 直接导出 NPZ 的 10ms 标注，不能将界面插值当成新的训练真值。

训练时每段切成 6 个不重叠的 5 秒输入，音频特征处理到 24kHz；标签归并到 100ms，每个输入 50 帧。短事件通过区间内活动保留，每条外部声源取该区间内有声帧的中间时刻作为位置，距离除以 100。一个类别在区间内有隐藏正例，或同类外部声源超过三个时，保守关闭该类别监督；自身活动取区间最大值，掩码取最小值。10ms 原始标注仍保留，不被 100ms 训练标签替换。

## 10. 划分、可复现与配置入口

原声家族在混音前按训练/验证/测试约 80/10/10 划分，Local/Remote 与 FPP/TPP 留在同一划分，原始 PCM 不跨划分。完整生成种子为 20260906，小集额外 `scene_seed=202609071` 仅改变场景，保持素材划分不变。

辅助素材整家族固定划分：

| 类型 | 训练 | 验证 | 测试 |
|---|---|---|---|
| 轮胎 | Dirt | Concrete | BuggySkidDirt |
| 碰撞 | common | brdm_light_dry | snowmobile |
| 天气 | sandstorm | wind_pillar | mode_storm |

某一划分上的成绩涉及素材家族变化，不能直接称为同一种天气的泛化精度。试听可以跨家族制作对照，但不能加入训练或独立测试评分。增强/镜像/变速派生物也留在原划分；比较增强方案时固定验证、测试及其清单指纹，不用测试集反复选择参数。

每批保留 `config.json`、`generation_identity.json`、`source_manifest.json`、`source_split.json`、`recipes.jsonl`、完整/分划分 manifest、`master_gain.json`、`summary.json`、`verification.json`。生成身份含 Python 文件、源清单、HRIR 哈希；manifest 含 WAV/NPZ 哈希。完整 v4 的旧内部数据名保留生成历史，不为产品改名回写已生成数据。

**输出的 `config.json` 和 `recipes.jsonl` 当前是登记证据，主生成命令不会把手工修改后的它们当作新配置输入。** 当前 CLI 支持数量、场景种子、试听/仅规划等开关，没有通用 `--config` 参数。

| 想调整的行为 | 实际修改入口 |
|---|---|
| 数量、只规划、试听、场景种子 | `generate_scenario_dataset.py` 的 `--split-counts`、`--plan-only`、`--preview-only`、`--scene-seed` |
| 车内保留概率、遮蔽门限、天气/碰撞概率 | `generate_scenario_dataset.configuration()`，由规划/标签函数读取 |
| 初始远处比例、布局概率 | 生成配置及 `generate_self_audio_dataset.plan()` |
| 自身策略、基础密度、脚步节奏、动作节点 | `generate_self_audio_dataset.plan()`、`motion_synthesis.schedule_footsteps()`、`scenario_synthesis.action_vehicle()` 等实际函数 |
| 距离衰减、1.6 倍远半径、2.5% 平台、活动门限 | 目前含核心函数内常量；相应配置中部分字段只作登记，必须同步实现与登记，不能只改 JSON |

修改前定位真正被读取的参数，修改后以新配方、音频与标签核对行为；已有 WAV 不会因为源码或登记文件改动而自动更新。

## 11. 按反馈调整与验收

1. 在[反馈记录](data_feedback.md)填写数据版本、样本 ID、时间段、现象和期望。用户可只判断方向/距离描述是否正确，不要求反推出精确角度或米数。
2. 对照同一时段的轨迹、活动、可观测性及原声，区分素材、事件节奏、轨迹、响度/空间化、遮蔽标签或模型训练问题。不依据一次低 F1 直接判定所有数据无效。
3. 把待调整项写成具体参数或行为变化；尽量一次处理一类问题，保留旧种子/对照片段，在新目录生成少量样本。分别登记“代码已改”“小样已生成”“已纳入全量”，不能相互替代。
4. 运行文件/标签核验，再试听新旧样本及易混淆对照，记录用户实际反馈。人工试听字段保持空白直到收到反馈，不自动填写“通过”。
5. 将采用的改动写回本规范和修订记录；数据规则改变时创建新数据版本，保留代码快照、素材划分、哈希和成品统计。仅更正文档描述时标记为文档修订，不冒充新数据版本。
6. 比较训练效果时，在同一模型/训练步数/划分条件下记录 W&B 实验，关注各类召回、近中远、车内遮蔽、碰撞误报及天气误报。数据版本和新增增强应能从运行配置追溯。

| 验收项目 | 要求 |
|---|---|
| 文件与音频 | 数量/划分正确，30 秒、44.1kHz、双声道 PCM16，峰值 ≤0.7，无非有限值，哈希对应 manifest |
| 标签 | 每轨每帧几何一致；自身方向无效；隐藏正例屏蔽；飞机不作负例；碰撞归车；纯天气目标类无活动 |
| 动作 | 同地面脚步变体交替、停步保尾音；车动作和位置一致；检查接缝、急刹/碰撞时间及速度突变 |
| 隔离与重放 | 家族/PCM 不跨训练验证测试；抽样覆盖车内、碰撞、天气，精确重放 PCM 及全部标签 |
| 试听 | 远处曲线脚步/车、走停、自身三类、近处外部反例、车内混合、碰撞对照、巡航与天气对照 |
| 统计 | 同时报计划比例与实际结果，区分发声帧、可观测帧、训练有效帧；新增统计字段注明起始版本 |

当前自动核验器已覆盖文件、几何、遮蔽、隔离和抽样重放；动作听感及是否像游戏仍需人工反馈。`summary.json` 的渲染状态可能保留为 `rendered_pending_independent_verification`，实际独立核验结论读取 `verification.json`，不只依据摘要字符串。

## 12. 常用生成命令

在子模块目录、Anaconda `pubg` 环境执行。下面是后续操作示例，本次文档整理没有执行生成。每次先换成未使用的输出目录。

```powershell
conda activate pubg

# 固定对照场景试听；不用于估算正式训练分布
python tools/synthesis/generate_scenario_dataset.py --sources datasets/sources-v4 --hrir datasets/hrir/kemar-diffuse.zip --output outputs/scenario-review-next --preview-only --workers 4
python tools/synthesis/verify_scenario_dataset.py --dataset outputs/scenario-review-next --sources datasets/sources-v4 --hrir datasets/hrir/kemar-diffuse.zip --reproduce 6
python tools/synthesis/export_motion_labels.py --dataset outputs/scenario-review-next --output outputs/scenario-review-next/逐帧标注
python tools/synthesis/build_scenario_preview.py --preview outputs/scenario-review-next

# 另生成少量随机场景做训练流程测试，种子与数量只是示例
python tools/synthesis/generate_scenario_dataset.py --sources datasets/sources-v4 --hrir datasets/hrir/kemar-diffuse.zip --output datasets/scenario-small-next --split-counts 48 12 12 --scene-seed 202609072 --workers 4
python tools/synthesis/verify_scenario_dataset.py --dataset datasets/scenario-small-next --sources datasets/sources-v4 --hrir datasets/hrir/kemar-diffuse.zip --reproduce 6
```

固定试听生成后打开目录中的 `试听与轨迹.html`，在页面或其反馈 CSV 中填写结果。当前页面构建器面向 `--preview-only` 配方，不能直接假定任意随机训练集都具有所需的试听标题等元数据。

## 13. 尚未实现或尚未采用

运输飞机正例、已核验暴风雪、REV 原发动机解码、完整车体/轮胎材质匹配、真实楼层/遮挡/混响、多普勒、玩家世界运动联动，均不在已完成能力中。

额外白/粉噪声、不同强度环境噪声、左右声道交换及标签镜像、FilterAugment/ITFM、20→40→80 小时训练扩充目前是[候选实验](augmentation_and_scaling.md)。现有天气、增益抖动和随机场景已生效，但不能据此称新增增强方案已完成。

新增噪声需重渲染分轨并重新计算可观测性。当前 NPZ 只保留背景/自身车功率，未保存每条声源的功率；禁止仅对已混合 WAV 加噪后原样沿用全部监督。未来是否保存额外分轨信息，应连同存储成本和标注版本一并记录。
