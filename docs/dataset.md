# v4 连续场景数据

本地全量目录 `datasets/audio-synthetic-20260907-v4`。WAV 为 44.1kHz 双声道 PCM16；每段 30 秒，2400/300/300 段独立划分，共 25 小时。所有音源复制或提取自现有客户端素材库，不下载替代声音。

## 场景与运动

先生成速度、连续朝向曲线并积分得到 XY，再沿路径加载原声。脚步同一角色始终同一地面，走/跑/冲刺只在该地面内部切换；左右脚为同材质原声变体的交替节奏，素材没有真正的左右脚标记。停步停止新落脚，保留尾音和累计步相位。

车辆包含启停、负载变化、急刹、停车再起步。恒速平台从旧生成器移动阶段的 18% 减至约 2.5%；实际状态帧比例另见登记报告，因为平滑插值中的低加速度帧也会被分类为巡航。制动用客户端轮胎/打滑层，碰撞用独立原声，标注为车辆，不标枪声。

车辆原生 REV `.model` 尚未解码。发动机仍是怠速样本变速和负载滤波近似；碰撞使用通用层，并不等价于精确车体物理仿真。船、地面车辆和运输飞机不能混为一类；当前飞机正例未补齐。

远处初始目标比例 80%；v4 实际外部有声帧约 **84.688%** 为远处。低、中、高密度场景的基础采样比例为 40/35/25；自身策略和天气负例会改变最终可听重叠度，实际计数记录于清单。

## 玩家在车内

- 外部脚步候选只保留约 10%；整段都在 90 合成单位之外的外部车辆候选保留约 5%。枪声不按这条规则统一删掉。
- 仍保留少量近处/可听反例。外部脚步相对自身车辆功率低于 −12dB，或远处车低于 −15dB 时，保留轨迹及发声真值但屏蔽正例监督。一般混合源沿用 −30dB 干扰比门限。
- 这些是可调合成假设，并非经过人耳或实战录音测得的听觉阈值。不是“一坐车就永久不识别脚步”。
- 自身身份由 Local/FPP/角色来源明确标注；近处外部声源仍是外部。自身方位无效、相对距离 0；外部不等于敌方，当前不能区分敌友。

## 易混淆声音

额外核验 30 个碰撞和 5 个天气原声。沙尘暴 Inner/Outer/Center 循环各一段；另有 PillarCompound 风声和 Mode_SLB Storm 环境声。后两者按原始名称记录，不冒充暴风雪。暴风雪 `Ambience3D_BlizzardZone_Loop_01.wav` 的媒体 ID 269897396 已发现，但没有完成独立音频定位/解码，因此没有作为已验证暴风雪加入。

天气是非定向背景，不伪造单个位置。707 段有天气，其中 141 段仅天气，对脚步、车辆、枪声为负例。训练/验证/测试的碰撞和天气录音家族完全隔离：训练沙尘暴，验证 Pillar 风，测试 SLB Storm；因此测试结果也不能直接当成沙尘暴泛化精度。

原声溯源链保存 bank/media ID、物理 PAK 条目、WEM/PCM/WAV 哈希。一些 bank 仅存流式前缀；必须以 RIFF 完整长度和逐字节前缀唯一匹配完整载荷，再验载荷哈希。重复物理条目只在完整字节一致时接受；禁止补零假造完整音频。

## 每帧标签

每段 2997 个分析帧，32ms 窗、10ms hop，标签时刻为窗中心减共同滤波延迟 64/44100 秒。无声和停住时仍保存位置。

| 数组 | 说明 |
|---|---|
| `track_xy`, `track_distance_units`, `track_azimuth_degrees` | 每声源每帧位置、距离、0°前/90°右/180°后/270°左 |
| `track_source_role`, `track_direction_valid` | 外部/自身来源及方向有效性 |
| `track_activity` | 孤立声轨发声真值；不是混音后的可听性 |
| `track_observable` | 按功率门限估算的可监督发声状态 |
| `activity`, `activity_loss_mask`, `range_loss_mask` | 外部类别/方位及距离监督、冲突/遮蔽屏蔽 |
| `self_activity`, `self_activity_loss_mask` | 三类自身声音的独立监督 |
| `track_collision_activity` | 碰撞原声事件时间支持，仍属于车辆类 |
| `weather_present`, `background_power`, `self_vehicle_power` | 天气/背景和自身车的干扰信息 |

NPZ 是训练真值；试听页按 50ms 路径点插值显示。CSV 导出直接读取每个 10ms NPZ 帧，不把界面插值当新标注。音频仅采用全数据集共同增益，无逐片段/逐耳归一化，v4 公共增益约 0.310746。

原生录音家族在混音前划分，Local/Remote 与 FPP/TPP 留在同一划分；素材级 PCM 不跨划分。训练集与试听页用途不同，试听页不得混入测试评分。全量读取、每帧几何检查与选定场景 PCM/所有标签精确复现报告在 `datasets/registry/`。
