## 实际启用的轻增强

1. 每轮每个训练场景均匀抽取12个五秒窗口，起点在0至115秒的100ms网格上，共1151个合法起点。每轮使用96 × 12 = 1152次采样，允许重复起点；不是把在线变化算成更多独立录音时长。随机性绑定种子、轮次和样本编号，不随DataLoader工作进程数变化。
2. 每个窗口以50%概率交换左右声道的空间特征：归一化前ILD及sin(IPD)取反，平均幅度及cos(IPD)不变；所有外部目标的x取反，y/z、距离及自身标签不变。该变换已与实际交换WAV左右声道后提取特征逐项比对。

标签仍使用100ms多源目标。缓存整段目标及32ms分析窗的支持范围；随机裁剪时重新屏蔽越过窗口边界的监督，外部和自身均适用。旧、新真实场景各39个随机起点与直接重新投影逐项一致。训练期实时读取选中音频窗口并提取特征；缓存只加速未增强的归一化拟合、固定验证和标签计划，不把一小组固定偏移冒充每轮随机裁剪。

归一化只拟合训练分区的全部2304个固定五秒窗口，之后用于随机训练窗口和固定验证/测试。本轮不额外加噪声、增益、变速或频谱遮挡；这些需要独立检查空间线索和可观测性，仍保留为后续方案。

## 训练协议

配置为 `configs/pubg_light_v5_3_gunvehicle_aug400.json`，新运行目录为 `outputs/train-light-v5_3-gunvehicle-aug400-20260907`。从相同初始化种子202609077重新训练，沿用106万参数论文骨干、ADPIT、自身头、Adam固定学习率0.001和batch16。RTX5070Ti，四个数据工作进程，显式关闭早停。

| 预算 | 上一版250轮 | 本次400轮 |
|---|---:|---:|
| 训练场景 / 独立音频 | 48 / 96分钟 | 96 / 192分钟 |
| 每轮采样 | 1152个固定窗口 | 1152个随机窗口 |
| 每轮参数更新 | 72 | 72 |
| 总参数更新 | 18000 | 28800 |
| 镜像概率 | 0 | 50% |

本次“轮”指一次1152次随机采样，不代表按顺序遍历192分钟的所有音频。400轮增加60%的参数更新，并持续改变观察窗口。骨干依然只看到五秒上下文；120秒原始场景不等于网络具有120秒记忆。

预先保留两种选模规则：`best.pt` 取最低总验证损失，`best_detection.pt` 取最高外部三类验证F1等权宏平均。固定检测阈值0.5，训练完再分别测试；不以测试结果选择轮次或改阈值。主要检测对比使用前后两个版本各自的 `best_detection.pt`，同时记录自身类别、定位条件帧数和方向/距离误差。测试划分已被查看，应称为固定合成测试集复评，不是新盲测或实战准确率。

W&B仅使用独立PUBGAudio项目，创建新run，上传配置与指标，不上传音频、源素材、权重或源码。源代码与数据清单哈希、两类模型和评估结果保存在本地。

## 复现与验收

以下命令中的输出目录必须是新目录；已有训练不可覆盖。确需恢复时使用原配方和原配置。

```powershell
conda activate pubg
python tools/synthesis/extend_light_dataset.py --parent datasets/light-v5_3-20260907 --spec configs/light_dataset_v5_3_gunvehicle.json --output datasets/light-v5_3-gunvehicle-20260907 --workers 2
python tools/verify_light_dataset.py --dataset datasets/light-v5_3-gunvehicle-20260907 --replay
python -m pubg_audio.train --config configs/pubg_light_v5_3_gunvehicle_aug400.json --dataset datasets/light-v5_3-gunvehicle-20260907 --output outputs/train-light-v5_3-gunvehicle-aug400-20260907 --device cuda --batch-size 16 --workers 4 --threads 4 --cache-dir datasets/cache-light-v5_3-gunvehicle-20260907 --wandb-config configs/wandb.local.json --evaluate-test
```

增强相关回归及全套64项测试通过；CUDA两批训练流程检查通过，它不用于效果结论。108段核验及4段精确重放通过；已完成400轮、28800次更新，训练/验证循环36.4分钟。两份权重导出参数与归一化一致，检测权重完成120秒CPU推理、1200帧有限值核验。W&B e6f7b62b7263为finished，轮数、两种选模轮次及12项测试F1远端一致。

按验证检测宏F1选择第339轮，外部测试脚步/车/枪F1为88.51%/93.10%/55.91%，父版分别为91.09%/85.86%/64.84%；宏平均80.60%→79.18%。车辆检测提升，但枪声和脚步检测退步，车辆条件方向误差55.16°→67.40°，不能称为整体升级。总验证loss规则选第229轮，外部测试F1为85.94%/90.90%/68.00%；两种预定规则都保留，未按测试结果回头改选模。详见[结果、曲线与模型](../outputs/reports/augmentation_gunvehicle_training_20260907.md)。
