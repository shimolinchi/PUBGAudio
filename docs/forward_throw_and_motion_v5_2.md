# v5.2 前向投掷、视角活动与车辆状态

更新：2026-09-07。根据本轮试听反馈生成 **14 段、940 秒（15分40秒）** 小样，目录为 `outputs/forward-view-preview-20260907-v5_2`。旧 v5.1 试听及反馈保留。正式25小时数据、网络和训练窗口尚未采用本版。

## 自身投掷方向

自身手雷、闪光弹和燃烧瓶在**离手瞬间**读取玩家朝向，按该朝向向前投掷。飞行路径绑定世界坐标，落地后的爆炸位置和燃烧位置保持固定。随后转头只改变耳相对方位、双耳波形及相应标签。

准备动作继续标为自身；离手后的爆响或燃烧只标事件、位置和可听性，不标投掷者。外部投掷不强行绑定本玩家视角。当前只模拟水平朝向，没有新增抛物线高度、墙体反弹、玩家平移或俯仰。

配方的关联事件链新增 `release_listener_yaw_degrees`、`release_forward_world`、`launch_direction_binding`。详细标签每10ms保留世界位置、玩家朝向、耳相对位置和方位，训练投影使用耳相对坐标。

## 实际配置

完整概率、持续时间和声学参数由 [generation_v5_2.json](../configs/generation_v5_2.json) 生成到 [概率表](generation_probability_v5_2.md)。以下是本轮变化；这些是可调的生成参数，不是游戏统计。

| 选择 | v5.1 | v5.2 |

| 自然段中小晃 / 观察 / 大转向 | 60% / 25% / 15% | 60% / 18% / 22% |
| 普通停留 | 2–8秒 | 0.35–1.6秒 |
| 长停留概率、时长 | 20%，10–25秒 | 12%，4–10秒 |
| 车辆后继加速权重 | 1 | 2.5 |
| 车辆后继巡航 / 熄火滑行权重 | 0.8 / 1 | 0.6 / 0.2 |
| 加速最短持续；之后每0.5秒切换概率 | 1.5秒；约16.7% | 3秒；10% |
| 滑行最短持续；之后每0.5秒切换概率 | 2秒；12.5% | 1秒；35% |
| 滑行最长持续 | 10秒 | 3秒 |

| 启动最短时段 | 3.5秒 | 1秒；原生启动素材更长则完整保留 |

视角幅度仍为小晃0.5–6°、观察8–35°、大转向60–160°，左右等权，平滑连接，最高角速度140°/s。车辆仍受加速度、合法状态衔接和速度上限约束；距最高速度不足2单位/s时，不再抽加速状态。保留少量滑车及碰撞覆盖，未额外放大滑车音量。

100个相同规划种子的比较见 [行为统计](../outputs/reports/behavior_probability_audit_20260907.json)。统计依据实际速度、速度变化和发动机状态，分母为车辆规划有效时段，不按状态名称计数：

| 指标 | v5.1 | v5.2 |
|---|---:|---:|
| 有动力且正在加速的时间占比 | 30.9% | 45.0% |
| 发动机开启、近乎静止的时间占比 | 19.6% | 12.2% |
| 发动机关闭且仍在移动的时间占比 | 14.2% | 2.1% |
| 每60秒视角动作数，含回摆及固定场景 | 5.19 | 22.03 |

这些指标只是验证生成调整方向，不能代表游戏发生频率、听感通过率或训练收益。有限小样不会精确凑成配置中的比例。

## 试听入口

| 样本 | 用途 |
|---|---|
| T01 / T02 / T03，各60秒 | 自身手雷 / 闪光 / 燃烧瓶。出手朝向35°，随后向右转110°，落点固定 |
| V01 / V02，各60秒 | 外部曲线车辆 / 自身车辆，检查加速、减速和短暂停留 |
| L01，120秒 | 自然轻晃、大转向、停留，以及脚步、车辆和自身投掷的连续场景 |
| A01，100秒 | 运输机完整世界直线通场，玩家视角频繁变化 |
| V03，60秒 | 特意保留的短滑车与碰撞对照，不计入随机出现比例 |
| R01–R06，各60秒 | 独立概率抽样。本批低密度2段、高密度4段，中密度未抽中 |

建议先听 T03 的4–17秒，再听 L01 和 V01/V02。T03 出手6秒，燃烧位置约15.2推定米、世界35°；玩家转到145°后，耳相对方向为250°。地图可切换世界坐标与相对玩家视角，旁边显示锁定的出手方向。

全部14段已通过文件、源哈希、时序、几何、标签与投影核验；T01/T02/T03/V01/L01精确重放通过。模块40个测试通过。人工听感仍待用户反馈，不把机器核验当作试听认可。声学半径、曲线和燃烧时长继续受 [v5.1 核查边界](attenuation_and_listener_v5_1.md) 限制。

## 复现

在子模块目录使用本机 `pubg` 环境，输出目录必须是新目录：

```powershell
python tools/synthesis/write_probability_reference.py --config configs/generation_v5_2.json --output docs/generation_probability_v5_2.md
python tools/synthesis/generate_behavior_preview.py --output outputs/forward-view-preview-NEW-v5_2
python tools/synthesis/verify_causal_preview.py outputs/forward-view-preview-NEW-v5_2 --replay T01 T02 T03 V01 L01
python tools/synthesis/build_causal_preview.py outputs/forward-view-preview-NEW-v5_2
python tools/synthesis/serve_preview.py outputs/forward-view-preview-NEW-v5_2 --port 8768
```

配方、配置、详细标签、三类投影、776个本地源的清单指纹和生成器快照均随输出保存。试听页的反馈写入该版本独立 `feedback` 目录。正式长片段和过去窗口训练仍按既有方案等待后续实施。

后续F027反馈：自身脚步可能偏响，目前的参考电平没有实录校准；播放音量与数字采集的区别及验收方案见 [采集与响度标定](audio_capture_and_level_calibration.md)。尚未据此改写本批音频。
