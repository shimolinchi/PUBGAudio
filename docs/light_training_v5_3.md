## 数据范围与概率

配置为 `configs/light_dataset_v5_3.json`，在 `generation_v5_3.json` 上应用如下裁剪。原始 v5.3 配置和历史试听不修改。

| 项目 | 本次设置 |
|---|---|
| 时长 | 60 段 × 120 秒 = 2 小时 |
| 训练 / 验证 / 测试 | 48 / 6 / 6 段，96 / 12 / 12 分钟 |
| 主要类别 | 脚步、车辆、枪声；均保留自身/外部来源 |
| 步态 | 行走 25%、跑步 41.67%、冲刺 33.33%，为合法步态选择概率，不是时长配额 |
| 密度 | 低/中/高各 1/3，逐场景随机采样 |
| 三类生成率 | 每个合法 0.5 秒时间步，低/中/高分别 0.008 / 0.018 / 0.035 |
| 自身来源 | 自身角色可用时概率 0.5，已有自身动作占用时不再追加自身角色 |
| 外部移动距离模式 | 远处 80%；近掠、中掠、靠近、远离各 5% |
| 曲线 | 直线、圆弧、正弦、Bezier 各 25% |
| 玩家转头 | 沿用 v5.2/v5.3：固定 10%、自然活动 90%，包含小晃、观察、大转及停顿 |
| 车辆动作 | 沿用加速偏多、巡航/怠速/滑车偏少的状态机；10% 合法移动车辆可发生碰撞 |
| 本次省略 | 蹲趴翻越、投掷物、C4、飞机、天气、车辆受击/损坏/爆炸链 |

枪型仍由已有六种有界开火配置选择，保留枪型细标签，但训练输出只有“枪声”。碰撞仍属于车辆轨，作为枪声的负例；没有为了训练伪造无前因的爆炸。

每条脚步角色保持同一地面，步态连续数秒、允许停步；不混用地面模拟左右脚。先生成运动与玩家视角，再渲染双耳音频；远声不逐段归一放大。声学半径和距离仍为合成设定，尚未实录标定。

## 隔离与素材限制

先按完整地面、车库/武器家族、辅助录音家族分区，再生成场景。训练有 222 个源文件，验证 76 个，测试 64 个，共 362 个。源 PCM 哈希和家族均不跨分区；完整两分钟场景及其所有五秒裁剪只属于一个分区。

| 分区 | 地面 | 枪型资产 | 车辆 |
|---|---|---|---|
| 训练 | Concrete / Dirt / Fabric | AK47 / M762 / MP5K / AWM | Buggy / CoupeRB / Dacia / PickupTruck / UAZ |
| 验证 | Rock | M16A4 | Rony |
| 测试 | Snow | Kar98k | Minibus / Sedan |

现有轮胎素材只有两组滚动/刹车录音家族和一组滑胎家族，无法让三个分区都拥有独立的全部轮胎层。本版训练使用 Dirt 滚动/刹车，验证使用 Concrete 滚动/刹车，测试使用 BuggySkidDirt 滑胎；缺失层明确省略，不从另一分区借音频。起步、发动机、熄火、运动/制动状态和独立碰撞仍保留。这也是本次保留家族评估的一个分布差异，不能把结果解释成完整车声覆盖。

原始详细标签保留 10ms 多声源；`*_train3.npz` 为三类投影。5 秒输入产生 50 个 100ms 多源目标，完整能量分析窗跨裁剪边界时屏蔽监督。被掩蔽目标继续保留真值并屏蔽损失。具体字段见 [标注与训练目标](annotation_and_training_targets.md)。

## 首轮轻量训练协议（F031）

沿用 3 CNN → 2 BiGRU → 2 MHA、ADPIT 和三类自身头，约 106 万参数。每次输入 5 秒，模型仍是离线网络；两分钟场景不代表网络已经获得两分钟上下文。

- Adam，学习率 0.001，batch 16，最多 80 轮，验证损失连续 15 轮未改善提前结束。
- 所有训练轮完整遍历 1,152 个训练裁剪；验证为 144 个裁剪。最佳权重仅按验证损失选择。
- 固定 0.5 检测阈值；每轮记录验证分类 F1/精确率/召回率及检出的单声源条件下方向/距离误差。最后只对选定权重进行一次独立测试，测试集不选参数。
- 归一化仅拟合训练集。可选特征缓存保存未经归一化的特征和已有目标，不改变样本或标签；缓存绑定文件清单、数据文件哈希、特征及标签适配代码。
- 本次无新增白噪声、频谱增强、声道镜像或在线增益增强。合成中的轨迹、状态、开始时间与原声变体随机性保留。
- W&B 显式绑定独立 PUBGAudio 项目，新训练 run；仅上传配置、清单指纹和指标，不上传音频、源素材、权重或代码。

```powershell
conda activate pubg
python tools/synthesis/generate_light_dataset.py --output datasets/light-v5_3-20260907 --workers 2
python tools/verify_light_dataset.py --dataset datasets/light-v5_3-20260907 --replay
python -m pubg_audio.train --config configs/pubg_light_v5_3.json --dataset datasets/light-v5_3-20260907 --output outputs/train-light-v5_3-20260907 --device cuda --batch-size 16 --workers 2 --cache-dir datasets/cache-light-v5_3-20260907 --wandb-config configs/wandb.local.json --evaluate-test
```

已实际完成30轮，验证损失连续15轮未改善提前停止，选择第15轮权重；独立测试已完成。推理文件 `outputs/train-light-v5_3-20260907/model.pt` 为4,291,579字节，导出参数一致性及120秒独立CPU推理通过。详细指标见[训练结果](../outputs/reports/light_training_v5_3_20260907.md)。W&B新run `aa19d2890dff` 已核实为finished，云端轮数、最佳轮次和六项测试F1与本地一致。相关测试58项通过。
