# 目标声音覆盖与评估划分修正（F035）

用户指出训练应覆盖实际使用中需要识别的全部枪型，主验证/测试应与这一使用分布相符。采用这一原则。旧400轮权重和报告保持历史事实。F036已实现类型覆盖与新的场景划分，24小时v6已生成并通过实际可听覆盖检查；采用下述稀缺素材条款中的“已知素材的新场景测试”，不称独立录音，见[本版规范](spatial_v6.md)。

## 现有划分测量的能力

F031/F034的隔离单位是整个武器声音组、整个车型和整个地面。枪声配置如下：

| 分区 | 当前枪型声音组 |
|---|---|
| 训练 | AK47、M762、MP5K、AWM |
| 验证 | M16A4 |
| 测试 | Kar98k |

三者的粗训练类别都是“枪声”，但枪型音色分布被人为分开。这样可以评估未见枪型的泛化能力，却不能作为“已知PUBG声音类型覆盖完整”的主要评估。我此前为了防止重复素材跨分区，使用了过粗的武器家族隔离；把它作为当前应用的主协议不合适。相同问题也存在于整车型、整地面留出。

56%仍是正确计算的第339轮外部枪声测试F1，但只来自当前Kar98k测试场景，不代表对全体游戏枪声的总体F1。原验证枪声F1约80%也不能代替全枪型评估。现有30/250/400轮记录均保留为相应的家族留出实验，不改指标数值。

覆盖审计还发现：当前源清单有50个武器声音组，生成器仅配置6组开火行为，轻量训练再选其中4组。50个声音组不等于50种已经完成语义、开火行为、自身/外部及配件覆盖核验的枪型，不能直接宣称全部可用。逐组数量、角色、PCM及配置状态见[审计JSON](../outputs/reports/weapon_coverage_audit_20260907.json)。

## 下一版主训练与评估原则

1. 在选定的脚步/车辆/枪声任务内，训练覆盖所有已收集、经语义和声音行为核实的目标枪型、车型、地面。先核对目标清单与实际生成记录，缺失项明确登记，不能因过滤器或缺少开火配置而静默跳过。不能只把M16A4、Kar98k补入，又继续忽略其他目标枪型。
2. 主训练、验证、测试使用相同的枪型及场景生成分布：沿用统一的密度、距离、自身/外部、曲线、转头、遮蔽和车辆动作概率。各分区独立种子；概率相同不要求最终样本比例逐项完全相等。按枪型及主要音色/角色分层，检查每个分区的实际可听正例覆盖。
3. 保持样本独立。按同枪型内部的独立原始录音/素材组划分；同一原录音的裁剪、近似重复、变速或镜像等派生项必须一起分配。PCM去重仍保留，但仅PCM哈希不同不足以证明录音独立。完整合成场景及其时间裁剪/增强始终留在一个分区，禁止把同一两分钟片段拆给训练和测试。
4. 有独立素材时，同枪型在三个分区分别用不同原始素材生成新场景。枪型可以重复，原始录音及其派生片段不能伪装成新独立录音。不能将近声全放训练、远声全放测试，或将自身/外部角色分别分区。
5. 某种枪只有一两个独立素材时，不能通过复制、改音量或换随机种子造出“三份独立录音”。应补充该枪的独立游戏录音；如为开发调试而在不同合成场景共享固定客户端源素材，必须单列为“已知素材的新场景测试”，说明共享来源，不称为独立原声/实录泛化测试。覆盖不足按角色与音色变体报告，不能为满足比例再次排除整个枪型的训练。
6. 原来的“整枪型留出”作为附加鲁棒性实验，使用单独训练且确实没看过被留出枪型的模型；训练已包含Kar98k的新模型，不能再把旧Kar98k场景称为未见枪型测试。另保留独立实录评估，检查合成到真实游戏的差异。

此处选择的是“类别覆盖相符、样本分组独立”的主协议。分层可以保留类别比例，分组隔离可以避免同组样本跨训练与测试，两者可以结合。[scikit-learn说明](https://scikit-learn.org/stable/modules/cross_validation.html#stratifiedgroupkfold)

测试集应代表实际使用数据，并排除训练重复样本；未见类型、设备或场景的挑战测试可以额外开展，其评价目标应单独说明。[Google机器学习课程](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets)

## 落地与结果口径

下一版需同时更新源级划分、开火行为覆盖、生成器过滤和覆盖核验，再生成新的训练/验证/测试清单；不是向当前训练集直接追加旧测试音频。先建立可听样本覆盖表，再确定满足各枪型/角色覆盖的数量，不能假定原来的12分钟单枪型测试量足够全枪型评估。

新协议会改变测试任务和样本，所得F1不能与当前56%直接解释为同一测试条件下的提升。旧配方归档、模型和报告保留；旧合成数据已按用户要求在新集核验后删除。v6数据已就绪，用户已明确授权并启动400轮正式训练，见[当前状态](spatial_v6.md)。
