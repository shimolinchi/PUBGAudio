# 连续场景、详细标注与训练目标

更新：2026-09-07。当前为 **v5.2 小批试听**，不是正式训练集发布。本玩家投掷方向绑定出手朝向，增加视角活动与车辆加速、减少怠速和滑车，见 [行为修订](forward_throw_and_motion_v5_2.md) 与 [当前概率表](generation_probability_v5_2.md)。沿用 [v5.1声学修订](attenuation_and_listener_v5_1.md)。本页其余机制继承v5；旧v4的25小时数据保持原样，不调整网络、不启动训练。

## 1. 数据详细，训练按需取用

详细数据同时保留声源轨迹、素材 ID、枪型素材名、步态、地面、车辆状态、动作时间、事件关系和可观测性。不要为了当前输出头较少而删除这些信息。

`configs/training_targets_v5.json` 决定当前三类训练适配器使用哪些标签。默认外部和自身均选脚步、车辆、枪声；从列表删除某一类即可关闭该类监督。类别槽位仍沿用现有模型，未扩大网络。飞机、投掷物操作、爆炸、燃烧、提示声和天气保留在 WAV 中作为干扰，不产生三类目标正例。碰撞、刹车和爆胎暂随车辆轨记录细事件，粗标签仍为车辆；如果需要将车辆的某些子事件也排除，须另加明确的事件级投影规则。

| 文件 | 内容 | 是否可删掉“不训练”的信息 |
|---|---|---|
| `recipes.jsonl` | 原声、动作/状态时段、随机选择、轨迹、事件关系、证据状态 | 否，作为完整生成记录 |
| `audio/ID.npz` | 10ms 一帧的详细位置、方位、距离、来源、活动/可观测性等 | 否 |
| `audio/ID_train3.npz` | 面向现有三类外部定位及三类自身标签的训练投影 | 可重建，不能覆盖详细 NPZ |
| `audio/ID.wav` | 全部已接入声源混音，32kHz 双声道 PCM16 | 不因目标筛选而移除干扰音频 |

“忽略类别”和“被遮蔽的目标”处理不同：只含爆炸而无脚步的时段可以成为脚步负例；脚步实际存在但被爆炸/车声遮住时，保留详细活动标签，将相应监督掩码设为 0，避免强迫模型猜测或学成错误负例。可观测性当前由分轨功率比估计，是合成启发式，并非人的听觉阈值。

自身标签只表示本玩家的直接动作。自己的拉环、点燃等标自身；离手后的爆炸、命中和燃烧仅标事件及物理位置，不标投掷者，也不作为自身正例。`external` 只表示不绑定听者，不能解释成“敌人”。配方中的准备→效果关联用于检查先后关系，不投影为效果的玩家身份标签。

## 2. 随机发生率受自然行为约束

配置实际读取入口是 `configs/generation_v5.json`。对应[概率表](generation_probability_v5.md)由同一 JSON 生成。先抽每条低/中/高密度，再每 0.5 秒对满足条件的类别抽样；开始一个角色/事件链后，按持续时间和合法状态推进。状态每 10ms 记录，但不会每 10ms 重新决定走跑或加减速。

维持率不是统一 50%。脚步至少持续 3 秒，之后每个调度步按 12.5% 概率结束当前步态段；车辆不同状态有自己的最短时长和切换率。车辆第一次加速还需满足随机抽出的行驶速度目标及有限加速度、最长持续时间约束。短片末端可以提前收尾，不为凑够比例跳变。

远处模式权重 80%；曲线类别及可用地面默认等权；巡航后继权重 0.8，其他合法后继通常为 1。权重在合法候选集合中重新归一化，**不是整条音频时长配额**。碰撞、受攻击属于一次车辆片段的条件事件，不能每帧重复抽。

独立随机 R 组保留真实抽样结果，包括安静样本和小批某一密度未抽中的情况。专项 S 组单列，覆盖 C4、投掷物、滑车碰撞、爆胎、起火爆炸和飞机，不并入随机概率统计。候选生成后还可能因自身车遮蔽策略被拒绝，候选抽中次数不能冒充最终声源数量。

要求事件在片内完整呈现时，末段会停止接纳新事件。目前 60 秒完整飞机仅在 t=0 有一次合法机会；这是试听片段边界的限制。正式长序列生成应先规划更长世界时间再裁剪，保存片前状态，以免尾段天然偏静。不要通过删除事件前因来填满尾段。

## 3. 当前已实施的自然过程

| 声音/行为 | 实际规则 | 证据与限制 |
|---|---|---|
| 脚步 | 同一角色固定地面；走、跑、冲刺、蹲行、匍匐按连续段发声，段间可以停步；速度平滑，沿按弧长采样的直线/圆弧/正弦/贝塞尔曲线移动 | 左右脚为同地面/步态内变体交替，不声称素材自带左右脚标签；v5.3追加有明确共享原声依据的姿态计划，细姿态不等于独有音色 |
| 枪声 | 已接入六种已知普通枪族的单次原声，按有限弹量和枪族节奏排布；栓狙逐发，有间歇 | 发射间隔是试听参数，未宣称复刻现版本枪械数值；弹匣用完停止，不无声无限换弹；火箭发射器不混入普通枪池 |
| 手雷 | 拉环/准备→可选提前计时→释放→飞行→计时爆炸；根据引爆时刻计算位置，可在飞行中爆炸 | 官方 17.2 给出手雷烹雷 5 秒、闪光弹烹雷 2.5 秒；不能把手雷位置固定在拉环点 [1] |
| 闪光弹 | 烹雷时 2.5 秒截止；不烹雷时释放后 5 秒截止；首次碰撞后 0.7 秒和截止时刻取较早者 | PC 官方 6.2 更新说明 [2]；轨迹仅水平投影，尚未模拟高度、真实墙体反弹 |
| 燃烧瓶 | 本玩家可直接点燃→投出→另一个位置破碎/起火→固定燃烧段 | 当前固定 10 秒是**待校准试听设定**，没有找到足够可靠的现版本 PC 持续时间依据；原声 WAV 长度不证明燃烧时间 |
| C4 | 约 4 秒放置操作→激活→16 秒提示声倒计时→原位爆炸 | 放置方式、时长据 35.2 [3]；倒计时及提示逐渐变急据 7.3 [4]；本机原声单个提示约 0.109 秒，频谱峰约 8.2kHz 是音色频率，**不是鸣叫次数/秒**；重复间隔仍为显式近似 |
| 车辆行驶 | 启动完整前奏，随后按速度/加速度驱动引擎负载和滚动声；短巡航、加速、减速、急刹、停车、熄火及重新启动 | 用原生怠速/启停等层进行变速和滤波近似，未解码 REV 完整引擎模型；初始行驶目标 12–24 合成单位/秒，不等同真实车型速度标定 |
| 熄火滑车 | 熄火后保留速度并逐渐衰减，轮胎继续发声；仍可制动、碰撞；重新动力加速前先启动 | 官方 4.2 明确支持行进中关闭发动机，并非“熄火立即停车” [5] |
| 爆胎 | 有针对该车的先行枪声和受击时刻→原生爆胎声→连续降速 | 当前只实现射击触发的损伤支线；不凭空加爆胎瞬态，不声称完整轮胎受力模型 |
| 车辆起火/爆炸 | 已受损车辆继续遭射击→发动机停止、燃烧 5 秒→原生车辆爆炸 | 官方 7.3 说明普通毁坏后延迟 5 秒；爆炸伤害存在直接摧毁例外 [4]。目前只生成普通射击分支；事故/爆炸直接摧毁分支尚未实现 |
| 空投运输机 | C130 原声，固定速度直线从极远进入、越过一侧再到极远离开，片内不停车或反向 | 俯视投影、完整 60 秒通场；滑翔机、呼救/特殊飞机未因此被当作 C130 |
| 天气 | 稀有、固定 12 秒声学片段，当前随机池仅选沙尘暴 | 12 秒是数据片段长度，不是整场游戏天气持续时间；未用沙尘暴替代暴风雪 |

事件前因在物理配方中必须存在，但不意味着前奏总能听到：例如远处拉环很轻、爆炸却可听见。不能为了听到每一个阶段而把前奏不合理地放大。

## 5. 验收与复现

先检查音频格式、非有限值、峰值、逐帧几何及来源掩码，再检查事件顺序与时间、可重放性、训练投影和网页播放。`verification.json` 记录机器核验；试听是否自然由用户反馈，不能自动写“已听通过”。

每批保存实际配置、训练投影配置、素材清单、配方、代码快照、文件哈希和验证结果。`verify_causal_preview.py` 的重放使用当前代码，并同时核对它与该批快照的哈希一致。修改规则后生成新数据目录；正式扩充之前还需完成音源家族的训练/验证/测试隔离。试听 R/S 组只是用途分组，**不是**训练与测试划分。

```powershell
# 子模块目录，Anaconda pubg 环境；后续运行请换新输出目录
python tools/synthesis/generate_causal_preview.py --config configs/generation_v5.json --target-config configs/training_targets_v5.json --output outputs/causal-review-next
python tools/synthesis/verify_causal_preview.py outputs/causal-review-next --replay R02 S01 S04 S06 S08 S09
python tools/synthesis/build_causal_preview.py outputs/causal-review-next
python tools/synthesis/serve_preview.py outputs/causal-review-next --port 8766

# 仅重建训练投影，保留详细 NPZ 与混音
python tools/synthesis/project_causal_labels.py outputs/causal-review-next/audio/S01.npz outputs/causal-review-next/audio/S01_selected.npz --config configs/training_targets_v5.json
```

本地网页服务绑定 `127.0.0.1`，支持音频字节范围请求，供浏览器拖动播放进度；没有上传素材到公网。打开服务根目录中的 `试听与轨迹.html`。
