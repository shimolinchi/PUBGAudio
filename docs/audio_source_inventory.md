### 自身声音覆盖与标注要求（下一版）

| 声音来源 | 本玩家版本的要求 | 位置和归属怎样记录 |
|---|---|---|
| 人物移动与动作 | 走跑、蹲行、匍匐、落地、翻越、游泳、跳伞，以及确认有原声的姿态切换 | 直接随玩家发声的身体/装备声可绑定听者；没有确认原声的动作先登记缺项 |
| 武器与操作 | 开枪、消音开枪、换弹、上膛、切枪、弹壳、近战等 | 自身直接武器声使用适用的 Local/近身来源；不把全部外部 WAV 调大当作已验证的自身视角 |
| 投掷物的直接操作 | 本玩家手雷/闪光弹拉环；燃烧瓶准备、点燃等有原声依据的动作 | 标本玩家直接操作；燃烧瓶不虚构“拉环”动作。共用拉环素材不硬标其音色足以辨认雷种 |
| 投出后的效果 | 手雷爆炸、闪光弹爆响、燃烧瓶命中/燃烧，以及其他离体效果 | **只标事件类别、位置、距离、方位，不标是谁投的，不作为自身声音正例**；即使由本玩家投出也相同 |
| 驾乘车辆与事故 | 玩家所在车辆的启动、怠速、加减速、刹车、碰撞、喇叭/门等适用动作 | 车内直接声和远离后的车辆位置分开处理；归属标签不代替车内/车外视角标签 |
| 场景交互与物品 | 本玩家开关门、治疗、物品操作、布设/使用装置等直接动作 | 身边直接动作与之后的独立场景效果分开；不沿因果链自动把后续声音继承为自身 |
| 天气与自主环境 | 天气不生成本玩家版本；自主鸟虫、公共运输机等按实际来源归为环境/公共源 | 玩家可驾驶的航空器、玩家触发的环境交互仍单独覆盖自身动作；不能把公共源强行改成自身 |

建议保留 `source_role=self/external/environment/unknown`，其中 `self` 指本玩家直接动作或玩家所在车辆等自身发声；离体的投掷物效果按外部事件处理，`external` 不表示一定由敌人触发。另记录 `emitter_id`、`emitter_type`、`action_phase`、`listener_bound`，逐帧保留实际位置。投掷物效果的公开标注和训练目标不添加投掷者身份；内部配方关联准备/飞行/爆炸时间，仅用于正确调度，不继承自身标签。

每帧仍标物理距离/方位和可观测性。直接动作的自身标签按场景事实及合适视角的原声生成；不根据音量或距离猜身份。共用素材且缺少可分辨线索时，对无法可靠监督的直接动作自身判断设置单独掩码；这条规则不要求追溯远处投掷物的投掷者。

验收按“类别 × 本玩家/外部 × 场景”统计覆盖率。有素材缺项或没有生成到的组合必须显示，不能报告为已全覆盖。短批次独立随机未抽中的类别，可另外制作明确标识的专项覆盖样本；随机主体与专项补充的实际比例分开统计。这里要求整个数据集覆盖，不要求每条音频同时塞入所有自身声音。

当前 v5 详细数据增加本玩家投掷准备等动作，完整“所有适用动作”覆盖尚未完成；v4 原数据仍只有自身脚步/车辆/武器。**用户已决定先不改网络**：现有三类自身头保持，细动作可只保存在标签中，其声音作为干扰；不能声称模型已识别全部自身动作。

| F02 等普通车辆片段 | 三段加速约 5.54/2.97/4.39 秒；普通减速约 3.81/3.23 秒 | 加减速保持连续，不能每个调度步任意反向跳变 |
| F02 急刹及中途停车 | 急刹 0.50 秒，中途停车约 1.39 秒，末尾制动 0.70 秒 | 短制动事件后进入合理的停/再启动状态 |
| F02 / C02 巡航对照 | F02 的恒速平台约 0.58 秒；C02 对照样本约 21.1 秒 | C02 是专门的巡航试听对照，不代表普通场景的占比 |

v5 已采用“状态最短持续时间 + 之后的切换概率”。调度步长与 10ms 标签帧率分开；切换只选合法后继，碰撞每个有合法运动时段的车辆片段至多抽一次，避免高频重复；启动/急刹不被普通状态切换任意打断。

以下值已写入 v5 配置，完整表见[实际概率表](generation_probability_v5.md)。人工听感仍待本次反馈：

| 连续状态 | 调度步长 | 最短持续时间 | 之后每步维持率 | 之后每步切换率 | 未截断时平均持续时间 |
|---|---:|---:|---:|---:|---:|
| 走/跑/冲刺 | 0.5 秒 | 3 秒 | 87.5% | 12.5% | 7 秒 |
| 车辆加速 | 0.5 秒 | 1.5 秒 | 83.33% | 16.67% | 约 4.5 秒 |
| 车辆普通减速 | 0.5 秒 | 1 秒 | 80% | 20% | 3.5 秒 |

表中首次随机决策发生在“最短时间 + 一个调度步”处。几何等待下，期望持续时间为 `最短时间 + 调度步长 / 切换概率`；片段边界、物理边界和合法状态限制会改变实际统计。后续先对持续时间分布和试听效果做校准，不把这些候选值称为已验证的新听感。

巡航的选择权重略低是另一项参数，不能只降低维持率导致碎片式巡航。短暂停车、急刹按对应动作时长和安全后继关系设置；碰撞没有“持续巡航一样的维持概率”。

## 6. 概率表的层次

| 层次 | 抽样内容 | 已接受的偏好 / 待用户调整 |
|---|---|---|
| 整条片段 | 低/中/高密度 | v5等权各1/3；旧版40/35/25%仅为历史规则 |
| 每个调度步 | 可否新生脚步、车辆、武器、投掷物、环境等 | 每类各有条件发生概率；允许同时出现，不要求相加为 100% |
| 状态持续 | 是否继续当前状态 | 按上一节的时长目标校准，由代理调整；不使用统一 50% |
| 状态切换 | 切换到哪个合法状态 | 无特殊偏好的候选先等权；巡航略少，碰撞另设事件概率与冷却 |
| 源与轨迹 | 武器/车型、地面、曲线、长度/时长档位、方向、来源 | 未指定的可用候选先等权；轨迹和状态要满足运动约束 |
| 距离 | 近/中/远、远→近、近→远等 | 远处更多；还需区分“初始距离占比”和“实际发声帧距离占比” |
| 天气 | 是否出现、具体天气、事件时长 | 出现概率低，事件采用配置中的固定时长；样本缺失的类别暂不可用 |
| 自身车遮蔽 | 坐车时外部脚步/极远车辆 | 保留已有抑制与可观测性标注要求，不能靠伪负例降低比例 |

独立随机抽样会有自然波动。下一版需同时展示配置概率、有效抽样次数、被约束跳过次数和实际占比，不承诺每条短音频都恰好满足总体比例。
