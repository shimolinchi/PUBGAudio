# 论文结构复刻范围

论文：Krause, Politis, Mesaros，*Sound Event Detection and Localization with Distance Estimation*，EUSIPCO 2024，[arXiv v2 正文](https://arxiv.org/html/2403.11827v2)。

这是依据论文和结构图重新编写的 PyTorch 实现，不是作者训练代码的逐行拷贝。当前复刻网络结构与训练流程，**没有复现原论文数据、随机划分、房间模拟或最终指标**。论文合成部分新增 1200 × 60 秒，即 20 小时；本地训练集沿用 20 小时量级，但内容是 PUBG 合成场景。

| 部分 | 本实现 |
|---|---|
| 双耳前端 | 24kHz，40ms 周期 Hamming，20ms hop，1024 FFT；去掉 DC，保留 512 频点 |
| 输入 | 双耳平均幅度、ILD、cos(IPD)、sin(IPD)，形状 4 × 250 × 512 |
| CNN | 3 个 Conv2d + BN + ReLU + MaxPool + Dropout，每层 128 通道 |
| 池化 | 时间 5/1/1，频率 8/8/4；输出 50 帧 × 128 × 2 |
| 序列层 | 2 层双向 GRU，每方向 hidden=128；tanh 后前后向逐元素乘积 |
| 注意力 | 2 层，8 heads，128 维；残差与 LayerNorm |
| 输出头 | Linear 128→128→输出维度，隐藏线性层间没有额外激活 |
| multi-ACCDDOA | 3 轨 × C 类 × (x,y,z,d)，线性输出；单源复制/多源置换 ADPIT MSE |
| multi-task | C×3 方向，tanh；C 距离，ReLU；两路 MSE |
| 优化 | Adam lr=0.001；最多 250 epochs；验证损失 patience=75 |

`paper_13class.json`：13 类、无自身头，multi-ACCDDOA 参数 **1,062,812**。13 类配置用于拓扑检查；本地数据只有三类目标，不能把未出现的论文类别当成已训练。

`pubg_paper_backbone.json`：保留同一主干，外部 3 类 + 自身 3 类头，参数 **1,064,231**。自身头为项目扩展；BCE 权重 0.5。自身身份来自生成来源，绝不由近距离阈值决定。

## 论文未给全的细节与矛盾

- 正文一处写 CNN 后频率维度为 4，但输入 512 与表中池化 8×8×4 得到 **2**。本实现按明确的输入和池化参数计算，GRU 输入 256。
- 卷积 3×3、BN、dropout=0.05、双向输出相乘、注意力残差归一化及 FC 无中间激活，参考作者领域相关的 [DCASE 2024 官方基线代码](https://github.com/partha2409/DCASE2024_seld_baseline)。该基线默认 CNN 通道数与论文不同，本实现使用论文的 128。
- 幅度按窗和归一，ILD 为 20log10 比值；低能量 IPD 置零，避免静音相位。上述数值约定以及按训练集逐通道/频率标准化都是明确记录的实现选择。
- 5 秒尾部补半窗，得到 250 个输入帧。原数据 10ms 标签合并为互不重叠的 100ms 目标窗，短事件在窗内取并集；移动源位置取该窗有声帧的中位时间位置。这种事件聚合是本地数据适配，不是论文的真实录音标注流程。
- 本地只有水平位置，方向约定 x 向右、y 向前、z=0；距离除以 100 训练，再乘 100 输出。数值是合成单位，未标定为游戏米数。
- 同类最多 3 个活动源；超过 3 个则屏蔽该类该窗。multi-task 无法表达同类重叠，重叠窗屏蔽。被遮住的正例保留真值且 mask=0；原数据飞机监督 mask=0。

## 当前验证与后续边界

两种论文头的前向和梯度、ADPIT 单源/双源/三源置换、静音特征、左右声道交换、标签边界、自身与近处外部区分均有测试。已跑训练—验证—checkpoint—恢复—离线预测的小规模 CPU 流程。

训练 smoke 的损失仅证明流程能执行，不能用作准确率结论。尚待完整 GPU 训练、事件去重、检测阈值校准和独立真实游戏评测。合成距离衰减、自身车辆与遮蔽阈值都需要真实录音检验；原论文的 BiGRU/注意力使用未来上下文，不能直接称为实时模型。
