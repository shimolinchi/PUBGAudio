# 小规模训练测试（2026-09-07）

仓库已设为公开。本轮新生成 72 段 30 秒音频，并使用 Anaconda `pubg` 环境完成 5 轮 GPU 训练与独立测试。结果证明程序可以训练和保存权重；当前外部声音检测仍未达到可用程度。

## 数据与环境

- 数据：`datasets/scenario-small-20260907`，训练/验证/测试为 48/12/12 段，即 24/6/6 分钟；切成 288/72/72 个不重叠的 5 秒输入。
- 新轨迹种子 202609071，素材家族划分沿用 v4。约 88.21% 外部有声帧为远处；18 次碰撞、16 段天气，其中 2 段纯天气；低/中/高密度为 29/25/18 段。
- 72 段音频与标签全部回读、哈希和几何检查通过；9 段覆盖不同条件的 PCM 与全部标签精确复现。三套划分无原声家族或 PCM 交叉。
- Python 3.10.20、PyTorch 2.8.0+cu128、CUDA 12.8、NumPy 2.2.6、SciPy 1.15.3；RTX 5070 Ti 16 GB。14 项测试通过，`pip check` 通过。保留原 Python 3.12 CPU 环境。
- 网络 1,064,231 参数；Adam 0.001；batch 4、workers 2、CPU threads 4。归一化仅由训练集拟合。本轮没有新增在线噪声或频谱增强。

## 训练与独立测试

| 轮次 | 训练损失 | 验证损失 |
|---|---:|---:|
| 1 | 0.29414 | 0.26578 |
| 2 | 0.25236 | 0.26686 |
| 3 | 0.22533 | **0.23529** |
| 4 | 0.18916 | 0.23752 |
| 5 | 0.19170 | 0.24153 |

5 轮训练与验证总计约 57 秒，不含环境安装和初始化。按验证损失选择第 3 轮 `best.pt`，没有用测试集选择轮次或调整阈值。对全部 12 段测试数据评估一次：总损失 **0.32602**，外部部分 0.17281，自身部分 0.30642；总损失为外部 + 0.5×自身。

| 类型 | 外部声音 F1 | 自身声音 F1 |
|---|---:|---:|
| 脚步 | 0 | 0 |
| 车辆 | 0 | 0.5278 |
| 枪声 | 0 | 0.6696 |

阈值固定 0.5，每 100 ms 判断该类是否存在，忽略被遮蔽的监督帧。外部三类预测均未过阈值，因此没有可报告的方向或距离误差，不能把它们记为 0。这是合成测试数据上的诊断 F1，不是官方 SELD 分数，也不代表真实游戏表现。

## 记忆检查与下一步

使用 `train_000016`、`train_000017` 各一个训练片段，从随机权重开始对固定 batch 训练 300 步。损失 0.9212→0.000543，已见训练片段外部检测 F1 为 1.0；权重不保留。这仅检查网络能否拟合这些片段，不能当作泛化准确率。

目前不能仅根据测试损失下降认定模型已学会外部脚步、车辆和枪声。下一阶段需在验证集检查充分训练、可听正例覆盖、各任务损失量级，再逐项比较数据增强与扩充。方案见 [数据增强与扩充建议](../../docs/augmentation_and_scaling.md)。完整 25 小时 v4 数据已存在，本轮尚未用它进行完整训练。
